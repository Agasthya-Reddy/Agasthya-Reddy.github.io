Chemical-plume-tracking drone

Autonomous hexacopter, built from scratch

Built an autonomous hexacopter drone from scratch with an electronic-nose and biological sensor unit. Onboard Jetson Orin edge compute runs a reward-based ML algorithm that detects airborne chemical compounds and autonomously tracks them to their source. It is useful for finding the sources of gas leaks and fires without a person in the loop.

A georeferenced 3D mapping tool combines live ArduPilot telemetry, GPS, and sensor readings so operators can watch the plume take shape while the drone works.

Built with
Jetson Orin, ROS2, PyTorch, ArduPilot, Intel RealSense depth cameras
What it does
Finds a chemical source on its own, avoids obstacles on the way, and maps the plume in 3D

Passive radar using Starlink signals

Field-tested at T-REX 26-3, the Department of War's Technology Readiness Experimentation event

Built the software-defined-radio pipeline (USRP B210, RTL-SDR V4, GNU Radio, and SDR++) and a CFAR detection algorithm that resolves every Starlink Ku-band downlink channel, so every Starlink satellite overhead can be detected passively.

With passive radar dishes, that same information lets us detect drone swarms without transmitting anything. We deployed and tested the system at T-REX 26-3.

Result
Passive drone detection at distances up to 5 km
Signal processing
CFAR detection across 12 downlink channels spaced 250 MHz apart
Hardware
USRP B210, RTL-SDR V4, Kymeta Skyhawk u8 terminal

Camera and radar fusion for drone swarm detection

Detection and tracking system

Built a pan-tilt-zoom camera system that runs inference locally on a Jetson AGX to detect high-speed drones. It estimates each drone's size, speed, altitude, heading, and payload, and logs every track to a SQL database.

A custom model, served through an internal API, fuses the camera, radar, and telemetry data to support late-stage swarm detection.

Result
96% effectiveness for late-stage swarm detection
Built with
Jetson AGX, SQL, a custom fusion model behind an internal API

Long-range LoRa telemetry module

Solo build

Designed a self-contained telemetry tracker on custom firmware. A LoRa link fuses GPS, barometric, and IMU data to localize an asset in 3D space, and the module talks to any laptop over serial.

You can strap it onto almost anything that moves and it phones home with full telemetry from kilometers away, even if the thing it rides on has no telemetry of its own.

Result
Localizes assets to 1 m at 10 km range, deployed company-wide
Built with
Custom STM32 firmware, LoRa, GPS, barometer, IMU

Blood pressure monitor

Best in Class

This blood pressure cuff relies on purely analog electronics to create an amplified voltage reading, which a microcontroller reads and sends wirelessly to any phone. It took months of troubleshooting and testing, but it ended up within 5% of a commercially available cuff.

I also built a web interface with a regression-tree chatbot (CART style) that lets you talk through your readings with an assistant. The whole application runs on 512 KB and needs no internet access, which helps in remote areas.

Software is easier to build than ever, but nothing replaces testing analog electronics on a bench.

Result
Readings within 5% of a commercial device
Signal chain
INA126P instrumentation amplifier, cascaded Sallen-Key filters, gain and DC bias
Software
Oscillometric algorithm for systolic, mean, and diastolic pressure, plus an offline assistant in 512 KB of RAM
